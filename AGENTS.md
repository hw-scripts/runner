# Співпраця Runner та Interface

- Runner (`D:\Google Drive\Runner`) та Interface (`D:\Google Drive\Interface\interface`) — два варіанти інтеграції з однією грою. Під час змін перевіряй, чи є відповідна функція або спільне виправлення в іншому репозиторії.
- Якщо зміна застосовна до обох і дозволена поточним завданням та доступом, узгоджуй поведінку з урахуванням архітектури кожного рушія. Не копіюй код без перевірки протоколу, локальних правил і відмінностей реалізації.
- Якщо синхронна реалізація недоречна або неможлива, занеси конкретну незавершену роботу до TODO відповідного репозиторію: поведінку, підтверджені дані та межі перевірки. Не позначай роботу виконаною без перевірки.
- Дотримуйся AGENTS.md і дозволів кожного репозиторію; спільні припущення про гру перевіряй на фактичних даних або HAR.
